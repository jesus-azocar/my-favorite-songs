##Hello there!

I developed this as a first full CRUD webapp using React. It uses localStorage as persistent data storage method. 

The project allows you to add your favorite songs, saving its name, author, lyrics and a link to its YouTube video. The list extracts automatically the video thumbnail, and once a song is selected, a modal opens rendering the video in an iframe, along with the full lyrics. You can edit and delete the songs too.

The project was my first CI/CD too, I used Vercel for automatic deploying. I learned basic REACT Components working, properties and state behavior, as well as the usage of useEffect.
